## ✨ Features

- ⚡ **Zero-Runtime Overhead**: Powered by **Astro 5**, compiling to ultra-fast static HTML with zero client JS bloat.
- 📺 **Retro-Futuristic Aesthetics**: High-contrast cyber-obsidian & phosphor palette, optional CRT scanline overlay, and synthesized mechanical switch audio feedback.
- 🔀 **Buttery Smooth View Transitions**: Seamless page transitions using Astro's `<ClientRouter />` with custom directional keyframes.
- 💻 **Interactive Browser REPL**: Run Shae code snippets (recursion, pipelines, task threads, safe navigation) right in the browser sandbox.
- 📊 **Cold Truth Telemetry**: Unedited, transparent benchmark comparisons across cold startup latency, RAM footprint, and loop iteration.

## 🛠️ Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build production static bundle
npm run build

# Preview build locally
npm run preview
```

---

## 🚀 Deployment

The site generates a static bundle in `dist/` that can be hosted on Vercel, Cloudflare Pages, Netlify, or GitHub Pages with zero configuration.
